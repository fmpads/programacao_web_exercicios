# Exercício - 15 tags html

Criar um arquivo index.html, utilizando 15 tags básicas do W3Schools (w3schools.com), comentando as tags no código para melhor compreensão. O aluno poderá escolher qualquer tag para criar seu conteúdo, exceto a tag img que deverá compor obrigatoriamente no arquivo, pois foi escolhida pelo professor.

# Ordem / Linhas / Tags utilizadas no arquivo:

1º - 3 - head - tag de abertura de cabeçalho
2º - 4 - meta - tag de informação do cabeçalho (charset, viewport e outros dados)
3º - 6 - title - tag de título
4º - 8 - body - tag de abertura de corpo
5º - 9 - h1 - tag de título principal
6º - 10 - p - tag de parágrafo
7º - 11 - a - tag de link
8º - 12 - img - tag de imagem (tag obrigatória escolhida pelo professor)
9º - 13 - figcaption - tag de legenda de imagem
10º - 14 - ul - tag de lista não ordenada
11º - 15 - li - tag de item de lista
12º - 19 - ol - tag de lista ordenada
13º - 24 - table - tag de tabela
14º - 25 - tr - tag de linha da tabela
15º - 26 - th - tag de cabeçalho da tabela
